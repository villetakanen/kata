# Kata 0.2.0

Kata 0.2.0 adds a sixth visual pattern, a choice framework, and an offline Lys
deck with worked before-and-after examples. This release is slide-focused.

## What changed

- Added the golden cut: an optional asymmetric composition that gives a primary
  message more room beside evidence or qualification. The reference explains
  fit, poor fit, adaptation, and the limits of the 61.8/38.2 proportion.
- Expanded the repertoire to six patterns and seven worked pairs across 14 Lys
  slides. The deck embeds Lys 1.2.1 and works offline.
- Added a versioned, fictional evaluation corpus with three briefs, a shared run
  protocol, adapters for Claude Code, Codex CLI, and pi, and structural/browser
  review tooling, plus regression checks for case/key integrity and runner
  protocol behavior wired into `npm run check`.
- Added a documented original evaluation of 27 attempts, with results reported
  by CLI and model condition, plus a separate nine-attempt corrective candidate
  check. The corrective run changes both the task prompt and candidate skill;
  it is not an isolated skill comparison. See the [evaluation report](../evals/report.md)
  and [case index](../../evals/cases/index.json).

## Evidence boundaries

The evaluation is a small harness-debugging exercise, not a controlled study of
reader comprehension or preference. The briefs contain explicit constraints
that reveal important parts of the expected response. No independent human
reader outcomes were collected. The report records agent choices, source-text coverage, quantitative encoding
issues, automated checks, rendering/print review, failures, and limitations
without claiming that Kata improves comprehension or that one CLI performs
better. The generated outputs also include layout and print defects; a source
fact present in HTML does not guarantee that it is readable or positioned
faithfully.

The checked-in gallery and deck passed the final review across 14 slides at
1440×900 and 390×844, with keyboard navigation, no-JavaScript content, and
14-page print checks. The delivered skill also passed a portable-copy check:
eight Markdown files and seven resolved links. See the [release review
evidence](../evals/release-review/verification.json) and [review archive](../evals/release-review/).

The golden cut uses 61.8/38.2 only as an optional spatial proportion. It does
not encode quantities, establish preference, or show that readers understand
a slide better.

## Use and checks

Open `examples/index.html` for the gallery or `examples/kata-lys.html` for the
14-slide deck. The delivered skill is `skills/kata/`; copy that folder to an
agent's skill directory to use it independently.

With Node 20 or newer, run `npm run build` to rebuild examples and
`npm run check` to check project invariants. Visual changes also need browser
review at presentation and phone sizes, keyboard navigation, no-JavaScript
reading, and print inspection.

The release build and `npm run check` passed. Repository contribution and
Git/GitHub workflow rules are documented in `.codex/README.md`; restart the
agent session after installing those rules so its instructions reload.
