# Kata 0.4.0

Status: released as [`v0.4.0`](https://github.com/villetakanen/kata/releases/tag/v0.4.0).
Source and bundled artifacts are published on GitHub; no website deployment is
part of this release.

This increment clarifies Kata's purpose and establishes its project visual
foundations. It does not complete the alignment of the portable skill or catalogue
with that purpose. The owner explicitly accepted this narrower release scope.

## Delivered

- Communication-led vision and six exploratory composition variants across two
  frozen briefs, with a gallery and offline Lys deck.
- Two design studies documenting typography and colour choices and rejected
  alternatives. Design exploration for this phase is complete.
- A [living design system](../../examples/design-system/index.html), canonical
  JSON tokens, generated CSS, bundled OFL fonts and live/offline Lys examples.
  Newsreader carries copy; Archivo navigation; Chivo Mono technical notation.
- White/ceramic documentation surfaces, silicate-black reading ink (#111217),
  Reasonable Colors raspberry navigation. Papers 1–3 and petrol accents are
  reserved for examples, with paper-coloured text on petrol highlights.
- The current study index uses shared styles; historical study snapshots retain
  their local appearance. No repository-wide restyling is claimed.
- A 30-line local `kata-dev-study` skill for the study workflow, outside the
  portable product, registered in AGENTS.md.
- A controlled four-output selection-guidance pilot, including frozen inputs,
  candidate/baseline skills, artifacts and a review. Results were mixed; the
  candidate was not promoted. The portable skill matches the pre-trial version.

## Existing catalogue: provisional

The six-form skill, field guide and older examples remain available from 0.3.0.
They do not yet embody the vision consistently. Golden cut is the closest
existing example in the owner's assessment. Neither renaming the examples nor
promoting the exploratory specimens establishes a replacement compositional
language. Catalogue/skill alignment is explicitly deferred, not completed here.

## Verification

`npm run build`, `npm run check`, and `git diff --check` passed at delivery.
The build changed no artifacts, and `skills/kata/` matches the frozen baseline.
Delivery review reused the recorded visual inspections below; no new browser
inspection was performed.
The shared-token checker covers generated token freshness, local links, fonts,
licences and the standalone deck's embedded tokens. The communication checker
retains source-integrity, offline packaging and deterministic rebuild checks.

See the [communication review](../evals/0.4.0-review/README.md),
[DS verification](../../examples/design-system/verification.md),
[colour study verification](../../examples/studies/02-colour-roles/verification.md),
[typography verification](../../examples/studies/01-reading-rhythm/verification.md),
and [pilot review](../../evals/experiments/communication-choice/review.md).
Desktop/phone, keyboard, no-JavaScript and browser-PDF reviews are recorded there.
No full WCAG certification, reader-comprehension improvement, cross-browser,
screen-reader, actual browser-zoom or physical-print coverage is claimed.
The local skill validator could not run because PyYAML was unavailable; its
frontmatter and 30-line limit were manually checked.
