# Kata 0.3.0

Kata 0.3.0 focuses on arranging supplied content and adds a six-slide offline
Lys field guide. Each form has a visible specimen, an explanation of where it
works, a consequential limitation, and a link to its portable reference.

## What changed

- The choice framework now explicitly permits retaining a suitable existing
  layout. Current work covers placement, available space, grouping, reading
  order, and emphasis supported by the brief. Content authorship, rewriting,
  internal chart/table redesign, and deriving relationships are outside scope.
- A shared layout-assessment reference consolidates checks across forms,
  including supported priority and readable qualifications. A number with its
  qualification is a small illustration, not a new pattern.
- The field guide reuses the existing fictional launch specimens across
  aligned comparison, whole and parts, nested groups, directed dependencies,
  time series, and asymmetric composition. The existing seven before-and-after
  pairs and 14-slide Lys deck remain available.
- README, vision, development instructions, delivered guidance, and example
  introductions now state the same current scope. Historical specimens are
  identified as such where they illustrate broader information authorship.
- The development harness includes the complete Lys 1.2.1 authoring skill,
  pinned to upstream commit `c553aa5dbc36d5c6ddd819051384fdaf05c8cfd0`.
  Its embedded runtime matches the unchanged vendored Lys 1.2.1 runtime.
  This dependency is outside the portable Kata skill.
- Project checks cover the pinned authoring dependency and deterministic
  field-guide coverage, identifiers, reference links, source integrity,
  explanation fields, and offline packaging.

## Use

Open [the field guide](../../examples/field-guide.html),
[the comparison gallery](../../examples/index.html), or
[the 14-slide deck](../../examples/kata-lys.html). Copy `skills/kata/` on its
own to install the delivered skill; neither the field guide nor the local Lys
authoring dependency is required for that installation.

With Node 20 or newer, run `npm run build` and `npm run check`.

## Verification and evidence limits

See the [0.3.0 review record](../evals/0.3.0-review/README.md) for the reviewed
artifacts, reading contexts, corrections, and remaining gaps. The field guide
is authored dogfooding evidence, not an independent measurement of agent
performance, reader comprehension, or preference. No new baseline-versus-candidate
model runs or reader studies were conducted for this release.

The six-form catalogue remains unchanged. Its long-term relationship to the
supplied-content boundary is unresolved; this release does not settle ownership
of information modeling or promise expansion. The golden-cut proportion remains
an optional spatial choice, not a quantitative encoding or an empirical claim
of better comprehension. The [0.2.0 evaluation](../evals/report.md) and frozen
evaluation inputs remain historical records.
