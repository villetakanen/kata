# Kata 0.5.1 — restore static-composition scope

Prepared 16 October 2026 after the Lys demo migration exposed a responsibility
error in 0.5.0. Package metadata is 0.5.1.

## Correction

Kata composes one specified static surface. Its forms and practices choose
placement, scale, grouping and space on that surface. The renderer owns viewing,
scaling, navigation and print behavior. A new authored surface can require a
separate composition; a viewer resizing a window does not instruct Kata to
change that composition.

Commit `6753a3d` mistakenly added responsive “narrow view” variants, a scrolling
phone document requirement and Lys lifecycle code to the portable skill. The
example and trial then checked that invented behavior rather than checking the
renderer contract. The 0.5.0 version bump itself changed only package metadata.

Version 0.5.1 removes the responsive instructions from the shared forms,
practices and integration guidance, makes the static unit explicit in the vision
and agent gateway, and restores Lys's fixed-aspect scaling in the current deck.
The gallery's surrounding web-document text can adapt; its slide specimens stay
fixed 16:9 compositions. Authored content, associations and order are preserved.

The live independent-trial prompt now asks for renderer scaling. Its README
marks the earlier responsive results as out-of-scope historical evidence. Frozen
trial inputs, outputs and recorded hashes were not rewritten. No new independent
generation was run. Older studies and catalogues remain historical artifacts.

## Verification

- `npm run build` and `npm run check` pass, including content-fidelity negative
  controls, portable resource checks, pinned Lys provenance and isolated build
  freshness. A new check rejects responsive/lifecycle instructions in the current
  portable guidance and generated demo adapter.
- Every slide in the current seven-slide deck and gallery was inspected at
  1440×900 and 390×844, with JavaScript enabled and disabled. Both retain the
  authored 16:9 geometry and spatial relationships. Portrait-phone text scales
  down with the slide; no larger-text reading mode is implied.
- ArrowRight, Home and End navigate the deck. Resizing retains selection and the
  normal inactive-slide accessibility state. No external asset requests or page
  errors were observed in the copied standalone files with the browser offline.
- Axe WCAG 2 A/AA and 2.1 AA scans found no violations on the seven desktop
  slides. This is bounded automated evidence, not a conformance certification.
- The gallery and deck each print seven 960×540-point pages. Every rasterized
  page was inspected; controls and gallery commentary are omitted.

See [the verification record](../../examples/presentation/verification.json) and
[visual evidence](../evals/0.5.1-review/). The inspected working tree includes
pre-existing palette refinements in the example files; those refinements are
preserved separately from this scope correction. Artifact hashes identify that
reviewed working tree. Review used Chromium, not physical devices or a screen
reader. The run does not measure comprehension or comparative design quality.

The coordinated Lys correction is version 1.2.5: the demo retains its accepted
palette and compositions while using normal Lys scaling and navigation.
